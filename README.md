Entry for the make.fun bounty [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

`main.py` (Python 3.13, standard library only) writes one funny line that a
hopeless tech support agent says to a desperate customer to
`/output/entry.txt`:

> Eleven restarts already, so this time please restart it standing up, the machine respects confidence.

Run it with:

```sh
python3 -P -s main.py
```
